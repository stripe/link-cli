Load this extension's link-wallet skill when using Link tools for wallet data,
purchases, or checkout. Use its discovered mount-prefixed name (for example,
link__link-wallet). It explains the configured token and Link's approval flow.

Use the wallet configured by the application. Never ask for access tokens in the
conversation. Creating a spend request is not purchase approval; check its current
status before using credentials. Do not repeat card numbers, security codes, or
payment tokens in conversational replies.
